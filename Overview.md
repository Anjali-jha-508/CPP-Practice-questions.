 # Practice programs based on "class and functions" in CPP
 
This page contains some practice questions in C++ regarding class and function of the class. It will include Function Inside the Class, Function Outside the Class , calling of function from class to main, etc.

### Function Inside the Class

> Function inside the class is not a different case, it is the same class and object thing we saw earlier, the functions which we have defined inside the class which are also called as member functions are further specifically called as "Function Inside the Class"

Programs given below are almost same as what we referred earlier, yet by this we can get a clear idea of what a basic question about function inside the class be asked as.
